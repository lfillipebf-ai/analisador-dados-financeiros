# Analisador de Dados Financeiros

Projeto de portfólio/estudo desenvolvido por **Luis Fillipe Backer Faria** para praticar análise de dados com Python, Pandas e SQL.

## Objetivo

Transformar dados de transações financeiras em informações úteis por meio de limpeza e tratamento de dados, análise exploratória, indicadores financeiros, consultas SQL, exportação de resultados e gráficos.

## Tecnologias

- Python 3.11+
- Pandas
- Matplotlib
- SQLite
- SQL
- Jupyter Notebook

## Observação

Os dados utilizados são fictícios e foram criados exclusivamente para fins educacionais e de portfólio.
